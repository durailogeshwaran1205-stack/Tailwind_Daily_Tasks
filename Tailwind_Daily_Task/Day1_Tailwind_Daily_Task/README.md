# College Application Form

A modern and responsive **College Application Form** built using **HTML5** and **Tailwind CSS**.

## 📌 Project Overview

This project provides a clean online college application interface where students can enter their personal, academic, and contact information, upload required documents, write a personal statement, and submit their application.

## ✨ Features

* Responsive design for desktop, tablet, and mobile
* Personal information section
* Address information
* Academic information
* Program selection
* Academic transcript upload
* Profile photo upload
* Personal statement
* Application declaration checkbox
* Save as Draft button
* Submit Application button
* Modern UI using Tailwind CSS

## 🛠️ Technologies Used

* HTML5
* Tailwind CSS
* Responsive CSS utilities

## 🚀 Getting Started

### 1. Clone or download the project

Download the project files to your computer.

### 2. Open the project

Open the project folder and locate:

```text
index.html
```

### 3. Run the application

Open `index.html` directly in your web browser.

You can also use **VS Code Live Server** for development.

## 🎨 Tailwind CSS

This project uses Tailwind CSS through its CDN:

```html
<script src="https://cdn.tailwindcss.com"></script>
```

Therefore, an internet connection is required for Tailwind CSS styles to load when using the CDN version.

## ⚠️ Note

This project currently provides the **front-end user interface only**.

The form does not yet have backend functionality for:

* Saving applications
* User authentication
* Database storage
* File storage
* Email notifications
* Application status tracking

These features can be added using a backend such as **Node.js, PHP, Python, or Java** with a database.
